### ᕙ(⇀‸↼‶)ᕗ Boss Build: Karakuri

**Karakuri** (からくり, "mechanical puppet") is the control panel for my homelab's LLM/GPU host — service orchestration, model management for llama.cpp and ComfyUI, TTS, and the animated avatar behind Kongroo. It coordinates a small roster of named AI lab members (Kongroo included), each with their own personality, because a plain chatbot is boring and I have a Future Gadget Lab to run. Built with Vue 3 + NestJS, because Grafana is too soulless for a one-person creative workshop. Sits behind Authelia SSO; details on the [public docs site](https://docs.phyberapex.de).
